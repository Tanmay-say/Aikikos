# Aikikos: an AI companion that cannot spend your money

M5StickC Plus2 (face) + Dabao/Baochip-1x (guard) + laptop gateway + Sepolia testnet. Status: workspace ready; see `PLAN.md`.

**Humans start here:** `docs/SETUP_WINDOWS.md` (now) or `docs/SETUP_MANJARO.md` (later), then Phase 0 in `PLAN.md`, then `python tools/doctor.py list`.
**AI agents start here:** `AGENTS.md`, then `PLAN.md`. Run `python tools/check_all.py` before claiming anything.

Quick UI preview (needs SDL2): `cd m5/sim && ./fetch_libs.sh && make preview && ./aikikos_sim_preview` (keys A and B are the buttons).
Docs: PRD, ARCHITECTURE, PROTOCOL, FACTS (what is verified and what is not), DECISIONS, TESTING, UI_SPEC, OPEN_QUESTIONS in `docs/`.
